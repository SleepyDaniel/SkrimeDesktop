## What is Skrime Desktop?

Skrime Desktop is a native desktop app that puts all your skrime.eu hosting in one spot. Just log in with your API token once, and you can easily manage servers, domains, TeamSpeak instances, SSL certificates, backups, and more without using a browser.

## Getting Started

**Requires:** Node.js 18+

```bash
git clone https://github.com/SleepyDaniel/SkrimeDesktop.git
cd SkrimeDesktop
npm install
```

**Dev (hot reload):**
```bash
npm run dev
```

**Production build:**
```bash
npm start
```

**Package installer:**
```bash
npm run dist
```

Outputs a platform-native installer to `dist/`. Or grab a prebuilt binary from [Releases](https://github.com/SleepyDaniel/SkrimeDesktop/releases).
